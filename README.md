# IoT CO5075 — Group 3

Monorepo for the IoT course project: ESP firmware, PC Gateway, ThingsBoard/CoreIOT assets, documentation, report, slides, and demo media.

- `docs/`: architecture, requirements, and interface notes.
- `firmware/`: firmware for ESP1, ESP2, and ESP3.
- `gateway/`: PC MQTT Gateway and local dashboard.
- `thingsboard/`: ThingsBoard/CoreIOT configuration exports.
- `present/`: report, presentation, and demo deliverables.

See [`docs/hardware-architecture.md`](docs/hardware-architecture.md) for the current system design. Keep credentials and tokens out of Git.
